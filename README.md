# Welcome.

I like building things when I notice something that could work better — or when I have a slightly ridiculous idea I want to try.

## Things I've built

### [LearningDesk — Knowledge Atlas](https://github.com/zhen01/learningdesk-knowledge-atlas)

[![LearningDesk illustrated interface](https://raw.githubusercontent.com/zhen01/learningdesk-knowledge-atlas/main/docs/atlas-preview.svg)](https://github.com/zhen01/learningdesk-knowledge-atlas)

AI makes it easy to learn something new and just as easy to forget it. I wanted a place where knowledge accumulates: a personal library that connects what I read across subjects and lets me trace an idea back to its source.

`Python` · `SQLite` · `Codex CLI` · `JavaScript`

### [Agentville](https://github.com/zhen01/Agentville)

[![Agentville illustrated headquarters](https://raw.githubusercontent.com/zhen01/Agentville/main/docs/current-interface.svg)](https://github.com/zhen01/Agentville)

Running several agents is easy; remembering what each one is doing is harder. What if my Terminal sessions looked like an office, with employees, roles and a place to keep their context? Agentville is my experiment with that idea.

`Node.js` · `JavaScript` · `SVG` · `Codex CLI`

### [NYC Activity Discovery](https://github.com/zhen01/nyc-open-data-pipeline)

Finding something to do in New York shouldn't require looking through ten different websites. I built a data pipeline to turn fragmented event listings into reliable recommendations — complete with data quality tests, historical snapshots and explicit handling of unknown information.

`Python` · `dbt` · `Postgres` · `FastAPI`

### [Market Data Quality Lab](https://github.com/zhen01/investment-data-pipeline)

How do you know the data behind an investment analysis is trustworthy, especially when information arrives late or contradicts itself? A small offline prototype exploring data contracts, point-in-time filtering and evidence-backed text extraction.

`Python` · `pytest` · `Data quality`

### [Puppy Pomodoro](https://github.com/zhen01/puppy-pomodoro)

<a href="https://github.com/zhen01/puppy-pomodoro"><img src="https://raw.githubusercontent.com/zhen01/puppy-pomodoro/main/Assets/my-dog.png" alt="Puppy Pomodoro desktop companion" width="130"></a>

Focus timers are pretty boring. I made one that looks like my dog and lets me earn treats for it while I work.

`Python` · `PyQt6` · `macOS`

### [Motion Studio](https://github.com/zhen01/Motion-Studio)

I wanted to try being an orchestra conductor from my desk. This is a playful, ongoing experiment with hand-tracking and synthesized music.

`MediaPipe` · `Web Audio` · `Canvas`
