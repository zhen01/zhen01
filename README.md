# Welcome.

A small collection of experiments.

### [LearningDesk — Knowledge Atlas](https://github.com/zhen01/learningdesk-knowledge-atlas)

[![LearningDesk illustrated interface](https://raw.githubusercontent.com/zhen01/learningdesk-knowledge-atlas/main/docs/atlas-preview.svg)](https://github.com/zhen01/learningdesk-knowledge-atlas)

AI makes information easy to access, but difficult to retain and connect. LearningDesk turns scattered learning materials into a persistent, interconnected knowledge atlas.

`Python` · `SQLite` · `Codex CLI` · `JavaScript`

### [Agentville](https://github.com/zhen01/Agentville)

[![Agentville illustrated headquarters](https://raw.githubusercontent.com/zhen01/Agentville/main/docs/current-interface.svg)](https://github.com/zhen01/Agentville)

Running multiple AI agents is easy; coordinating them is harder. Agentville turns scattered terminal sessions into a visual office with roles, workflows, and shared context.

`Node.js` · `JavaScript` · `SVG` · `Codex CLI`
