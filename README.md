# Welcome.

A small collection of experiments.

## Selected projects

### [LearningDesk — Knowledge Atlas](https://github.com/zhen01/learningdesk-knowledge-atlas)

[![LearningDesk: Make what you read connect](https://raw.githubusercontent.com/zhen01/learningdesk-knowledge-atlas/main/docs/atlas-preview.svg)](https://github.com/zhen01/learningdesk-knowledge-atlas)

A local-first learning workspace that turns documents into a persistent, source-linked knowledge graph. It keeps previously extracted concepts, connects related ideas across disciplines, and lets readers revisit passages, annotate them, or listen aloud.

`Python` · `SQLite` · `Codex CLI` · `JavaScript`

### [Agentville](https://github.com/zhen01/Agentville)

[![Agentville: A visual headquarters for AI agents](https://raw.githubusercontent.com/zhen01/Agentville/main/docs/current-interface.svg)](https://github.com/zhen01/Agentville)

A visual headquarters for multiple AI agents. Inspect active sessions, organize work into roles and departments, and preserve context across handoffs.

`Node.js` · `JavaScript` · `SVG` · `Codex CLI`

### [Motion Studio](https://github.com/zhen01/Motion-Studio)

An experiment in gesture-based interaction: conduct a synthesized orchestra or use hand gestures to launch websites.

`MediaPipe` · `Web Audio` · `Canvas` · `JavaScript`
